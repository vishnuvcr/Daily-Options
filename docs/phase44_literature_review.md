# Phase 44 Literature Review

Recent NIFTY gap studies report that gap behaviour changes with gap magnitude rather than following one uniform continuation/reversal rule. A 2016–2026 Nifty 50 gap analysis reports different intraday behaviour across gap-size bands and emphasizes that large gaps are rarer and behave differently from routine openings. A separate 2026 NIFTY 50 analysis likewise reports gap-size-dependent fill behaviour. These sources are hypothesis-generating rather than evidence of profitability after option transaction costs; Phase 44 therefore tests fixed magnitude buckets with realistic friction and a preregistered promotion gate.

Sources: Intraday Lab, “Nifty Gap Down History: What Happens After a Panic Open?” (2026); Intraday Lab, “Nifty Gap Up History: Do They Actually Fill?” (2026).
