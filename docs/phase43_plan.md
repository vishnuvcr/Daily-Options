# Phase 43 — NIFTY Weekday × Opening-Gap Direction

State is the trading weekday (Monday–Friday). The current opening gap is 09:15 NIFTY open divided by the prior completed 15:10 close minus one. Zero gap is no-trade. Each weekday is tested with FOLLOW_GAP and FADE_GAP at 10:30 and 15:10 using a one-lot 200-point ATM directional debit spread, nearest expiry on/after trade date, historical lot sizes and the existing Paytm Money/NSE/statutory cost model. Base/Stress slippage is ₹0.20/₹0.40 per option-price unit/order. Five fixed full-panel weekday-label permutation nulls are used. Promotion requires mean and median weekly net ≥₹5,000, positive-week rate ≥70%, ≥95% execution coverage and clean accounting in both Base and Stress. No weekday is selected or tuned after observing results.
